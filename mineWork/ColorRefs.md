## 🔄 ACCESSIBILITY

### Color Contrast Ratios (WCAG AA)
```
PASS ✓  #292524 on #FFFFFF  →  12.51:1  (Excellent)
PASS ✓  #57534E on #FFFFFF  →  7.21:1   (Good)
PASS ✓  #FFFFFF on #FF6B9D  →  2.89:1   (Large text only)
PASS ✓  #FFFFFF on #A855F7  →  3.18:1   (Large text only)
PASS ✓  #E7E5E4 on #292524  →  11.94:1  (Excellent - Dark mode)
```

### When to Use Which Contrast
```
BODY TEXT (16px):     Minimum 4.5:1 contrast
LARGE TEXT (18px+):   Minimum 3:1 contrast
UI ELEMENTS:          Minimum 3:1 contrast

Safe Combinations:
✓ #292524 text on #FFFFFF bg
✓ #57534E text on #FFFFFF bg
✓ #FFFFFF text on #FF6B9D bg (18px+ only)
✓ #FFFFFF text on #A855F7 bg (18px+ only)
✓ #E7E5E4 text on #292524 bg (dark mode)
```

## 💡 QUICK TIPS

### Choosing Colors
```
❓ Main action button?        → Use Romance Gradient (#FF6B9D → #FFA06B)
❓ Anonymous feature?          → Use Purple Gradient (#A855F7)
❓ Group feature?              → Use Blue-Cyan Gradient (#3B82F6 → #06B6D4)
❓ Success message?            → Use #84CC16 (Lime Green)
❓ Error message?              → Use #EF4444 (Red)
❓ Subtle background?          → Use Neutral-100 (#F9F7F6)
❓ Card background?            → Use #FFFFFF with Neutral-200 border
❓ Muted text?                 → Use Neutral-400 (#A8A29E)
❓ Body text?                  → Use Neutral-500 (#57534E)
❓ Headings?                   → Use Neutral-600 (#292524)
```

### Color Psychology
```
🌸 PINK/CORAL:     Romance, warmth, approachability, love
💜 PURPLE:         Mystery, anonymity, creativity, trust
💙 BLUE:           Community, stability, professionalism
💚 GREEN:          Success, growth, positivity, safety
❤️ RED:            Urgency, error, attention, passion
💛 YELLOW:         Warning, caution, optimism, energy
```

## 🎯 REMEMBER

1. **Always test colors in both light and dark mode**
2. **Check contrast ratios for accessibility**
3. **Use gradients sparingly** (only for emphasis)
4. **Keep neutral colors consistent** across all pages
5. **Feature colors should be distinct** (pink=chat, purple=anon, blue=groups)
